## Keymap notes

- `MAIN`: Base QWERTY layer.
- `MOVE`: Navigation and mouse-click helper layer.
- `SYM`: Symbols and brackets.
- `NMF`: Numbers, function keys, and system controls.

Planned cleanup:

- Split `NMF` into safer `NUM`, `FN`, and `SYS` layers.
